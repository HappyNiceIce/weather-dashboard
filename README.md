# Weather Dashboard

## Опис проєкту

Weather Dashboard — це навчальний проєкт для моніторингу погодних даних. Його основна мета — надати користувачу можливість переглядати основну інформацію про погоду для вибраного населеного пункту.

## Основні можливості

- Перегляд поточної температури.
- Відображення вологості повітря.
- Перегляд швидкості вітру.
- Відображення атмосферного тиску.
- Пошук погоди за назвою міста.

## Використані технології

- C#
- .NET 10
- Git
- GitHub

## Структура проєкту

- `src/` — файли основної програми.
- `tests/` — файли для тестування.
- `docs/` — документація проєкту.

## Поточний стан

На початковому етапі виконується налаштування репозиторію та організація структури проєкту. Реалізація функціоналу буде виконуватися поступово.
