# Weather Dashboard

## Опис
Weather Dashboard — навчальний проєкт інформаційної панелі для моніторингу погодних та сенсорних даних.

## Статус проєкту
Проєкт перебуває на початковому етапі розробки.

На поточному етапі:
- створено Git-репозиторій;
- сформовано початковий backlog;
- налаштовано Project Board;
- визначено базовий Git workflow;
- програмна реалізація буде виконуватися у наступних лабораторних роботах.

## Заплановані можливості
- перегляд поточних показників датчиків;
- перегляд показників за обраний період;
- обробка помилок джерел даних;
- позначення застарілих даних.

## Технологічний стек
- C#;
- .NET 10;
- Git;
- GitHub.

## Вимоги до середовища
- .NET SDK 10;
- Git 2.x.

## Початок роботи
Клонувати репозиторій:

```bash
git clone https://github.com/HappyNiceIce/weather-dashboard.git
cd weather-dashboard
git status
```

На цьому етапі програмна реалізація ще не додана.

## Структура проєкту
- `src/` – вихідний код;
- `tests/` – тести;
- `docs/` – документація.

## Робота з репозиторієм
Для кожної задачі створюється окрема короткоживуча гілка, пов'язана з номером Issue.

Основний workflow:
Issue → Branch → Commit(s) → Pull Request → Review → Merge → Done

Формат назв гілок:
- `feature/<issue-id>-<name>`
- `fix/<issue-id>-<name>`
- `docs/<issue-id>-<name>`
- `chore/<issue-id>-<name>`

Приклад: `docs/2-readme`

Формат повідомлень commit: `<type>(<scope>): <короткий опис>`

Приклади:
- `feat(sensors): додано відображення показників`
- `docs(readme): доповнено документацію проєкту`
- `fix(source): виправлено обробку помилки джерела`
- `chore(repo): оновлено службові файли`

Зміни до main вносяться через Pull Request після перевірки.
Детальні правила будуть описані в `docs/CONTRIBUTING.md`.
